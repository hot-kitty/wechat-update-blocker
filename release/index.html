01 / THE GAP

只锁住 EXE，
还不够。

xwechat 可以把新的更新程序解压到插件目录，再将其写入 update 目录完成替换。针对某一个既有文件的“禁止执行”规则，无法覆盖这条新路径。

01

释放

微信将 WeixinUpdate.exe 释放到插件的 extracted 子目录。

02

替换

更新组件将新程序写入 xwechat 的 update 目录，绕开旧文件 ACL。

03

锁住链路

本工具将拦截点上移到目录层级，让未来新文件也自动受限。

02 / DEFENSE

从“文件”到“路径”的防护。

选择“屏蔽更新”后，工具执行可回滚的 ACL 和计划任务操作。所有状态直接读取系统 ACL，而非只记录一次点击结果。

01

结束当前更新进程

先关闭正在运行的更新器，避免文件被占用或继续执行。

02

阻止已有更新器执行

对检测到的更新 EXE 拒绝 Users 组执行权限，兼容自定义安装目录与微信 4.x 版本目录。

03

锁定未来的释放与替换

目录规则继承到后续创建的文件，阻止写入、新建、删除、覆盖和执行。

04

禁用更新计划任务

禁用而不删除，选择“允许更新”后即可重新启用，完整回滚。

LOCKED TARGETS / %APPDATA%

%APPDATA%\Tencent\xwechat\XPlugin\Plugins\WeixinUpdate
%APPDATA%\Tencent\xwechat\update
若 xwechat 根目录已经存在而目标目录尚未建立，点击屏蔽时工具会先创建并锁定对应目录。
03 / PROOF

看得见的拦截结果。

防护生效后，更新器无法再被直接启动；微信的更新尝试也不会绕过已锁定的更新路径。

04 / USE

三步完成防护。

没有后台驻留，没有不可逆删除。需要更新时，按相反方向恢复即可。

01

管理员运行

双击 EXE 并确认 UAC 授权。工具需要修改 ACL 与计划任务。

02

确认检测结果

检查安装目录与防护对象；找不到安装目录时可手动浏览选择。

03

应用设置

选择“屏蔽更新”后点击应用。需要更新时改为“允许更新”并再次应用。
